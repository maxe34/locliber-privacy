# locliber-privacy

The privacy policy and support pages for **LocLiber** (`md.cucerenco.locliber`),
served by GitHub Pages from `main` at the repository root.

| Page | URL | Used as |
|---|---|---|
| `index.html` (Romanian) | `https://maxe34.github.io/locliber-privacy/` | the privacy policy URL in App Store Connect and in the app's paywall |
| `ru.html`, `en.html` | `…/ru.html`, `…/en.html` | the same policy in Russian and English |
| `support.html` | `…/support.html` | the support URL in App Store Connect |

The three language versions say the same thing. Change one, change all three,
and move the effective date on each.

`Legal.privacyPolicy` in the app points here. If this URL ever moves, that
constant and the App Store Connect fields move with it — a policy link that
404s is a review rejection.

The policy describes what the app actually does: encrypted identity fields,
queries made under one subscriber's identity per centre, deletion from inside
the app. If any of that changes in the backend, the text here is part of the
change.
